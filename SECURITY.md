# Security Policy

## Supported Versions

The following versions are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** report it publicly via GitHub Issues. Instead, report security issues directly by opening a private disclosure or contacting the maintainers via Discord/email.

We review security reports promptly and aim to respond within 48 hours.
